# DSC-MD1 English cheat sheets

The DSC-MD1 was sold only in Japan, and every label, menu and message is in Japanese. These
phone-sized images translate all of it.

| File | Contents |
|---|---|
| `MD1-cheatsheet-1-quick-howto.png` | The common tasks: shooting, playback, sound with photos, fine mode |
| `MD1-cheatsheet-2-buttons-switches-part*.png` | Every button, switch, jack and label on the body |
| `MD1-cheatsheet-3-camera-menu.png` | Recording menu, every option |
| `MD1-cheatsheet-4-playback-audio-menu-part*.png` | Playback and audio menus |
| `MD1-cheatsheet-5-messages-part*.png` | On-screen messages and what to do |
| `MD1-cheatsheet-6-icons-words-part*.png` | Icons and common words |
| `MD1-menu-map-{1,2,3}-*.png` | Each menu tree as a left-to-right map |
| `md1_cheatsheet_data.json` | The translations as data (source for the images) |

The relabelled diagrams (`MD1-diagram-*.png`) are drawn over illustrations from Sony's manual,
so they are kept out of the public repository.
